
### Conways Game of Life
A reimplementation of Conways Game of Life inside objectpascal, developed in the Lazarus IDE. This is just a side project I decided to do out of curoisity for all the native programming conventions used inside the Lazarus IDE.

### How To Use The Simulation
To play around with the simulation, you can use the viewport controls at the bottom of the 504x504 pixel viewport. They can allow for starting/pausing, clearing the cell grid and adjusting simulation speed. The top viewport label contains information like coordinates and zoom level for navigation.
